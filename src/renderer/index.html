    Chat alerts (ping)

    When someone else's chat message contains one of these words, the line is highlighted and (if enabled) a ding plays. Whole words, not case-sensitive. Your own messages never ping you. Mute quickly with the 🔔 button above the chat.

    Performance & background

    Changes to low-memory mode and view distance apply on the next connection.

    Privacy & local data

    • Network: the only network connection is to the Minecraft server shown in the top bar. No analytics, telemetry, or update checks.
    • profiles.json: server name, host, port, username, version, reconnect, AFK and join-command settings. No passwords.
    • settings.json: the options on this page.
    • secrets.json: only if you tick “Remember securely”: login passwords encrypted with your OS account (Windows DPAPI). Otherwise passwords live in memory until you quit.
    • Chat and logs are kept in memory only, unless you export them.
